# TD-117 日历重写：跨月溢出预览列 + 色块完整入退房日期与状态角标

**优先级** P2 · **状态** 已完成 · **来源** US-1106-17 · **模块** 房间与预订

**为什么做**：用户三点要求 —— ① 已入住房间（未满/已满）要显示入退房时间并带「入住中」tag；② 预定要显示入退房时间并带 tag；③ 跨月（11-30 → 12-01）只能看到 11-30，同一页看不完全信息。已拍板用**下月溢出预览列**方案。

**现状**【核实】：`RoomCalendar.tsx` 视窗 `to` 固定为次月 1 日，跨月色块被截到月末；色块文字是「姓名·备注 || MM-DD→MM-DD」，无状态角标；入住色块只有背景无文字。

**改动点**
1. **视窗扩展**：`overflowDays` 按当月数据（预定 `checkOut`、客卡到期日）超出月末的最远天数取 **0–7 封顶**（无跨月数据不加宽）；`days` 扩为「当月 + 下月 N 天」（`month.date()` 越界进位），`gridWidth` 自动跟随；`to = 月末 + N + 1` 作为 `spanOf`/`guestSpanOf` 上界，11-30 → 12-01 的色块完整画出。
2. **溢出列渲染**：`d.month() !== month.month()` 判定，日期号显示 `M/D`（如 `12/1`）、浅灰 `#f5f5f5` 底、字色次级；今天/周末高亮按绝对日期继续生效；拉取范围改固定「当月 + 下月 7 天」（`queryTo`）避免循环依赖。
3. **色块信息**：新增 `shortRange`（同年内 `MM-DD → MM-DD`，跨年带年份）——预定色块文字 = `日期区间 · 姓名 · 备注`，入住色块 = `入住 日期区间`；两者右上角各加小号角标「**预定**」/「**入住中**」（fontSize 10，半透明底）；`paddingRight` 留位。
4. **截断兜底**：`truncMask` 在色块顶到视窗右缘（超出溢出窗口）时右端 18px 渐隐，tooltip 始终含完整起止日期。
5. 过去日期锁定（TD-112）、半格错位（TD-110）、房号列 tag（TD-114）均未动。
