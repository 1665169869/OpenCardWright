# TD-129 应用显示名统一为「门锁发卡台」

**优先级** P2 · **状态** 已完成 · **来源** US-1106-31 · **模块** 工程与发布

**为什么做**：`OpenCardWright` 只是项目英文名，用户要求界面标题与**桌面快捷方式**都显示「门锁发卡台」。

**现状**【核实】：显示名散落在 6 处——`tauri.conf.json` 的 `productName`（决定安装包 / 快捷方式 / 安装目录名）
与窗口 `title`、`index.html` 的 `<title>`、`App.tsx` 顶栏与关窗确认框、`main.rs` 托盘 tooltip 与启动失败文案、
`AuthGate` 登录标题。

**改动点**：以上 6 处统一改为「门锁发卡台」；`identifier`（`io.opencardwright.desktop`）保持不变，避免数据目录
与升级链断裂。

**验收标准**
- [x] 窗口标题、`index.html` 标题、顶栏、登录页、关窗确认框、托盘 tooltip 均显示「门锁发卡台」
- [x] `productName` 改为「门锁发卡台」→ 桌面快捷方式与开始菜单名同步
- [x] 前端不再有用户可见的「OpenCardWright」文案（代码注释与工程文档保留英文项目名）
- [x] `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：`productName` 改中文后安装包文件名与安装目录变为中文（`门锁发卡台_…-setup.exe`、
`Program Files\门锁发卡台`）；**已装旧版（OpenCardWright）需先卸载**，否则会出现两个程序。需重新
`pnpm tauri build` 才能进安装包。
**待拍板**：无（用户明确要求含桌面快捷方式名）
