# TD-409 日志页自动到期卡仍显示「有效」

**优先级** P1 · **状态** 已完成 · **来源** US-1106-6 · **模块** 记录与运维

**为什么做**：发卡记录页的状态列只判断 `checkedOutAt`，自动到期但未退房的卡永远显示绿色「有效」，与到期时间矛盾；前台据此会以为卡还能用。

**现状**【核实】：
- `src/pages/Logs.tsx:264` 状态列：`r.checkedOutAt ? <Tag>已退房</Tag> : <Tag color="green">有效</Tag>`，没有判断 `expiresAt`，也没有判断 `result`。
- `IssuanceRow` 已有 `result` / `expiresAt` / `checkedOutAt`（`src/api.ts:160`），数据齐全，只是渲染漏了。
- 页面打开后没有定时重渲染，即使补了判断，到点也不会自动变，需要刷新 / 切页。

**改动点**
1. 状态列改为派生：`result !== 'ok'` → 失败；`checkedOutAt` → 已退房；客卡且 `expiresAt <= now` → 已过期；否则有效。
2. 客卡判定只对 `日租客卡` / `钟点客卡` 做过期判断，管理卡不因 `expires_at` 显示过期。
3. 加一个 60 秒的轻量 tick（只触发重渲染，不重新查库），让状态在页面停留时自动更新；不引入轮询查询。
4. 状态色统一：失败 / 过期红、已退房灰、有效绿。

**验收标准**
- [x] 一张 `expires_at` 已过的客卡显示「已过期」，不再显示「有效」
- [x] `checked_out_at` 非空的卡仍优先显示「已退房」
- [x] `result !== 'ok'` 的记录显示「失败」，不误标有效
- [x] 页面停留跨过到期时刻后，状态在 60 秒内自动变化
- [x] `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：纯前端渲染；`Date.parse` 对后端 ISO UTC 字符串有效。管理卡 `expires_at` 不参与过期判断。
