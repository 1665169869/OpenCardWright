# TD-137 设置-设备：选串口即生效

**优先级** P1 · **状态** 已完成 · **来源** US-1106-39 · **模块** 工程与发布

**为什么做**：用户反馈「探测后选了新串口没有自动保存并切换」——原来必须再点一次「保存并切换」，
而且探测结果表里的「选这个」只把下拉改了，根本没切换。

**改动点（`DevicePanel.tsx`）**
1. `savePort()` 改为 `switchPort(next)`：`api.setPort` 成功后同步 `info`/`port`，并提示
   「已切换到 COMx（已自动保存，下次启动沿用）」，同时 `onChanged()` 让主界面刷新设备状态。
2. Select 的 `onChange` 直接调 `switchPort`；探测结果表「选这个」同样直接切换。
3. 切换期间 Select 禁用、按钮 loading；失败时把下拉回滚到 `info.port` 并弹错误。
4. 删掉「保存并切换」，改成「重新连接」（切到同一串口即重试）；说明文字改为「选串口立即生效并自动保存」。

**验收标准**
- [x] 下拉选中即切换并落 setting，无需再点按钮
- [x] 探测表「选这个」会真正切换
- [x] 切换失败时下拉回滚到当前生效值并报错
- [x] `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：`set_port` 会重建设备实例；切换瞬间正在进行的持卡操作会失败——已在说明里提示切换前退出原门锁软件。
