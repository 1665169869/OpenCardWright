# TD-216 软件窗口不应置顶

**优先级** P1 · **状态** 待办 · **来源** US-1109-9 · **模块** 工程与发布

**为什么做**：用户要求软件窗口不要始终置顶，能被其他应用正常遮挡，不抢占前台。

## 现状

- `app/src-tauri/tauri.conf.json` 的窗口配置当前没有 `alwaysOnTop` 字段。
- 因此置顶可能来自：
  - 窗口创建代码 / Tauri 插件运行时设置；
  - 系统层窗口扩展或安装器快捷方式属性；
  - 旧版本残留的窗口状态；
  - 第三方壳或远程桌面工具行为。
- 不能只改配置就认定解决，需要先定位实际设置来源。

## 改动点

- [ ] 全局搜索 `alwaysOnTop` / `set_always_on_top` / `topmost` / `SetWindowPos(HWND_TOPMOST)`。
- [ ] 检查 `main.rs` / `lib.rs` 的窗口创建、托盘恢复、单实例唤醒逻辑。
- [ ] 检查 Tauri 插件、Windows 扩展、安装器快捷方式是否设置置顶。
- [ ] 明确移除或显式设置 `alwaysOnTop: false`，并确保运行时不重新置顶。
- [ ] 托盘恢复/再次启动唤起窗口时保持普通层级。

## 验收标准

- [ ] 启动主窗口后，其他应用可以正常遮挡它。
- [ ] 切页、打开弹窗、托盘恢复、再次启动唤起都不会把窗口抬到最前并保持置顶。
- [ ] 安装版与 dev 版行为一致。
- [ ] 关闭/重启后不恢复置顶状态。
- [ ] 不引入窗口无法唤起、最小化后找不回等回归。

## 待拍板

- 是否保留“启动时短暂置前”以便用户找到窗口？建议只做一次 `set_focus`，不设置 `alwaysOnTop`。
