# TD-216 软件窗口不应置顶

**优先级** P1 · **状态** 已完成 · **来源** US-1109-9 · **模块** 工程与发布

**为什么做**：用户要求软件窗口不要始终置顶，能被其他应用正常遮挡，不抢占前台。

## 现状（登记时）

- `app/src-tauri/tauri.conf.json` 的窗口配置没有 `alwaysOnTop` 字段。
- 因此置顶可能来自：窗口创建代码 / Tauri 插件运行时设置、系统层窗口扩展或安装器快捷方式属性、
  旧版本残留的窗口状态、第三方壳或远程桌面工具行为。
- 不能只改配置就认定解决，需要先定位实际设置来源。

## 改动点

- [x] 全局搜索 `alwaysOnTop` / `set_always_on_top` / `topmost` / `SetWindowPos(HWND_TOPMOST)`
      —— 全仓无匹配；`app/` 下也没有任何置顶相关配置或调用。
- [x] 检查 `main.rs` / `lib.rs` 的窗口创建、托盘恢复、单实例唤醒逻辑
      —— 只有三处 `window.set_focus()`（单实例唤醒、托盘左键/菜单「显示」），
      这是「叫到前台」而非置顶，不会让窗口一直压在其它应用之上。
- [x] 检查 Tauri 插件、Windows 扩展、安装器快捷方式
      —— `tauri.conf.json` 的 `app.windows[0]` 只有 label/title/尺寸/最小尺寸，无置顶字段。
- [x] 明确无需移除或显式设置 `alwaysOnTop: false`；运行时不重新置顶。
- [x] 托盘恢复 / 再次启动唤起窗口时保持普通层级（仅 `show` + `unminimize` + `set_focus`）。

## 验收标准

- [x] 启动主窗口后，其他应用可以正常遮挡它 —— 用户 2026-11-10 确认现象已不存在，本条可关闭。
- [x] 切页、打开弹窗、托盘恢复、再次启动唤起都不会把窗口抬到最前并保持置顶 —— 代码无置顶调用。
- [x] 安装版与 dev 版行为一致 —— 同一份 `tauri.conf.json`，无环境分支。
- [x] 关闭/重启后不恢复置顶状态 —— 置顶状态从不写盘，也没有持久化设置项。
- [x] 不引入窗口无法唤起、最小化后找不回等回归 —— 本轮未改任何窗口代码。

## 待拍板

已定：不保留「启动时短暂置前」以外的任何置顶行为；现有单实例/托盘唤起只用 `set_focus`，不设 `alwaysOnTop`。
