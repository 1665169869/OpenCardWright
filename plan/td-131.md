# TD-131 前端包管理改用 pnpm

**优先级** P2 · **状态** 已完成 · **来源** US-1106-33 · **模块** 工程与发布

**为什么做**：用户要求统一改用 pnpm——安装更快、依赖隔离更严格、lockfile 更小。

**现状**【核实】：原来是 npm + `package-lock.json`；且 `src/` 里直接 `import '@ant-design/icons'`、
`import dayjs`，但 `package.json` 只声明了 `antd`——npm 的扁平 hoist 掩盖了这个**隐性依赖**，
换 pnpm 的隔离结构立刻暴露（`tsc` 报 `Cannot find module`）。

**改动点（已执行）**
1. 装 pnpm 12.18（`npm install -g pnpm`）；删 `package-lock.json` 与 `node_modules`，生成 `pnpm-lock.yaml`。
2. `package.json`：scripts 里 `npm run build:sdk` → `pnpm build:sdk`；**补显式依赖**
   `@ant-design/icons@^5.6.1`、`dayjs@^1.11.23`（原先靠 hoist，pnpm 下必须声明）。
3. 新增 `app/pnpm-workspace.yaml`：`allowBuilds: esbuild`——pnpm 12 默认不跑依赖的 postinstall，
   esbuild 需要它校验平台二进制，缺这行 `pnpm install` 会以 `ERR_PNPM_IGNORED_BUILDS` 失败。
4. `src-tauri/tauri.conf.json`：`beforeDevCommand`/`beforeBuildCommand` → `pnpm dev` / `pnpm build`。
5. CI（`.github/workflows/ci.yml` 重写）：加 `pnpm/action-setup`、`cache: pnpm`、
   `pnpm install --frozen-lockfile`、`pnpm build:sdk`、`pnpm exec tsc/vite`；顺带把 `paths`、
   `working-directory`、rust-cache 里的旧目录名 `opencardwright` 修成 `app`。
6. 文档：AGENTS.md / app/README.md / plan/待办清单.md 里所有 `npm run|install|ci|npx` 改为 pnpm；
   README 前置依赖表加 pnpm 行；AGENTS §8 补 pnpm 版本与 `allowBuilds` 不能删的说明。

**验收标准**
- [x] 删掉 `node_modules` + `pnpm-lock.yaml` 后 `pnpm install` 干净通过（11s，esbuild postinstall 正常执行）
- [x] `pnpm build` 全过（`pnpm build:sdk` 27/27 门禁 + `tsc --noEmit` + `vite build` 3054 modules）
- [x] `package-lock.json` 已删除，`pnpm-lock.yaml` 入库；`.gitignore` 的 node_modules 规则覆盖 pnpm 结构
- [x] CI 配置改 pnpm（本地无法跑 GitHub Actions，配置按 pnpm 官方写法核对）

**依赖 / 风险**：`pnpm-workspace.yaml` 的 `allowBuilds: esbuild` 不能删；旧开发机切过来要
`rm -rf node_modules && pnpm install`（npm 的扁平结构不能复用）；pnpm 版本按 12.x 记录。
**待拍板**：无（用户明确要求改用 pnpm）
