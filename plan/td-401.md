# TD-401 发卡记录 / 日志页 + CSV 导出

**优先级** P1 · **状态** 已完成 · **来源** ST-4, RM5, P15 · **模块** 记录与运维

**为什么做**：现在留痕只能查单张卡（读卡命中时），没法「看今天发了哪些卡」「导出给财务」。这也是 README §6 第 3 条点名的未实现项。

**现状**【核实】：`issuance` 表已有 `raw_hex`、`expires_at` 与客人身份列，`audit_log` 表与 `record_audit` 存在；
但 store 只有 `latest_issuance_for_card` / `count_issuance_for_card` / `expiring_cards`，**没有列表查询**；
前端页签只有 rooms / read / admin / settings，无日志入口；全仓搜 `csv` 只命中一句错误提示文案。

**改动点**
1. `ocw-store`：加 `list_issuances(filter)`（房号 / 卡号 / 卡型 / 时间范围 / 分页）与 `list_audits(filter)`；必要时补索引。
2. `commands.rs`：加 `list_issuances`、`list_audits`、`export_issuances_csv`（写操作才要管理员，纯查询前台也应可用）。
3. 新页 `src/pages/Logs.tsx`：两个页签「发卡记录」「操作审计」+ 筛选条 + 表格 + 「导出 CSV」。
4. 卡片数据日志：按 `card_no` 聚合，展开看每次写入的 `raw_hex` 与时间。
5. 入口：先放「设置」的二级页签（与设备页同级）。要提成一级页签再改 `App.tsx` 的 `tabs`。

**验收标准**
- [x] 可按房号 / 卡号 / 卡型 / 日期筛选，结果条数与直接查库一致（单测对比 `COUNT(*)` 口径）
- [x] CSV 用 UTF-8 BOM，Excel 打开中文不乱码，含 `raw_hex`（单测断言 BOM/CRLF/转义/公式前缀）
- [x] 同一张卡多次写入能在展开行里按时间排列（`card_history` 正序）
- [x] 前台账号打开该页不报错（列表 `require_login`，导出仅管理员）

**依赖 / 风险**：CSV 建议后端生成字符串 + 前端 `Blob` 下载，不引入新 crate；数据量大必须有上限或分页。
**待拍板**：无（入口先按设置二级页签做，若改主意在执行时更新本条）
