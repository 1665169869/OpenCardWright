# TD-122 入住记录「查看详情」（弹窗显示登记的身份信息）

**优先级** P1 · **状态** 已完成 · **来源** US-1106-22 · **模块** 记录与运维

**为什么做**：入住列表只有房号 / 客人 / 卡号等摘要列，发卡时登记的完整身份信息（性别、证件类型与号码、民族、出生日期、住址、备注）在界面上看不到，前台核对或排查时要回原始表查。

**现状**【核实】：`Logs.tsx` 的 `CheckinTab`（TD-118）只有列展示、无详情入口；`IssuanceRow` 已带全部 `guest*` 字段（`guestName/gender/idType/idNumber/nation/address/birthDate/note`），发卡记录页也未展示 —— 数据齐全，纯前端改动、零后端。

**改动点**
1. `CheckinTab` 行尾加「详情」按钮（或整行可点，执行时二选一），打开受控 Modal。
2. Modal 用 `Descriptions` 展示发卡时登记的全部身份字段：姓名 / 性别 / 证件类型 / 证件号码 / 民族 / 出生日期 / 住址 / 备注；未填字段显示「—」。
3. 与发卡记录的行展开形式区分（**已拍板：点击弹窗**）；只读展示，无编辑入口。

**验收标准**
- [ ] 点击行/详情按钮弹窗，八个身份字段齐全，空字段回退「—」
- [ ] 与发卡记录（行展开）形式并存不冲突
- [ ] `pnpm exec tsc --noEmit` 通过；零后端改动

**依赖 / 风险**：证件号码属敏感信息，仅本地应用内展示（与发卡记录同权限口径），不新增导出。
