# TD-116 日历显示入住时间段色块（有效客卡发卡日 → 到期日）

**优先级** P1 · **状态** 已完成 · **来源** US-1106-16 · **模块** 房间与预订

**为什么做**：用户报 —— 发卡后按日历应该能看到「某个时间段已经入住」，但日历上只有房号旁的入住 tag，没有时间段色块，看不出从哪天住到哪天。

**现状**【核实】：`RoomCalendar.tsx` 只有预定色块；`rooms` 自带 `activeCards` / `activeUntil`（最晚到期），但**没有起始日**，无法直接画时间段。

**改动点**
1. `RoomCalendar` 加 `guestSpans` state + `useEffect`：并行拉 `list_issuances`（日租客卡、钟点客卡各 `pageSize: 200`），按有效口径过滤（`result='ok'`、`cardNo` 非空、`checkedOutAt` 为 NULL、`expiresAt > now`），按房取 `createdAt` 最新一条，转本地日期 `[发卡日, 到期日]`。
2. `guestSpanOf` 算视窗内坐标：含到期日当天、跨月截断到视窗边缘、不相交不画。
3. 渲染浅绿垫底色块（`rgba(82,196,26)`，`zIndex: 0`，`pointerEvents: 'none'`）——预定色块（`zIndex: 1`）在上层且仍可点击，空白格点击不受影响。
4. 拉取依赖 `reloadToken`：发卡 / 退房触发房间 reload 后日历重拉，色块即时出现。

**验收标准**
- [x] 发卡后切到日历，该房出现发卡日 → 到期日的浅绿色块
- [x] 与预定色块叠放时预定在上层，两者都可见
- [x] 色块不挡空白格预定与色块改期点击（pointerEvents none）
- [x] 跨月、已过期（不再拉取）、无有效卡的房间表现正确
- [x] `cargo test --workspace` 118 项全绿；`pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：复用记录页同口径的 `list_issuances`（登录级），200 条分页对 30 间房的有效卡绰绰有余；到期日按发卡时间估算（锁按首刷起算），色块 tooltip 已注明。
