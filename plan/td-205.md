# TD-205 预定记录支持导出 CSV

**优先级** P1 · **状态** 已完成 · **来源** US-1109-3 · **模块** 记录与运维

**为什么做**：预定记录页（`Logs.tsx` 的 `ReservationTab`）目前只能查询和分页查看，不能像发卡记录/入住记录那样导出 CSV；前台做交接、对账或给店长留档时需要手工抄。

**现状**（登记时）
- `app/src/pages/Logs.tsx`：`ReservationTab` 只有房号、姓名、状态、入住起止日筛选和表格，没有导出按钮。
- `app/src-tauri/src/commands.rs`：已有 `export_issuances_csv`，只导发卡记录；后端没有预定导出命令。
- `ocw-store` 的 `ReservationFilter` / `search_reservations` 已能按房号、姓名、状态、日期查询，可直接复用。

**改动点**
1. [x] 后端新增 `export_reservations_csv(filter)`，按当前筛选条件查询，不把分页当作导出范围。
2. [x] CSV 列：房号、客人姓名、入住日、入住时间、退房日、退房时间、晚数、状态、备注、操作员、创建时间、取消时间；
       状态输出中文（有效预定 / 已入住 / 已取消）。
3. [x] 前端 `ReservationTab` 增加「导出 CSV」按钮，复用发卡导出的路径选择与 UTF-8 BOM 写法；
       文件名 `预定记录-YYYYMMDD-HHMMSS.csv`。
4. [x] 导出按钮仅管理员可见（`canAdmin`），空结果只写表头，错误提示与发卡导出一致。

**完成形态（2026-11-10）**
