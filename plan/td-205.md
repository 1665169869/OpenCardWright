# TD-205 预定记录支持导出 CSV

**优先级** P1 · **状态** 待办 · **来源** US-1109-3 · **模块** 记录与运维

**为什么做**：预定记录页（`Logs.tsx` 的 `ReservationTab`）目前只能查询和分页查看，不能像发卡记录/入住记录那样导出 CSV；前台做交接、对账或给店长留档时需要手工抄。

**现状**
- `app/src/pages/Logs.tsx:497-650`：`ReservationTab` 只有房号、姓名、状态、入住起止日筛选和表格，没有导出按钮。
- `app/src-tauri/src/commands.rs:3191`：已有 `export_issuances_csv`，只导发卡记录；后端没有预定导出命令。
- `app/src-tauri/crates/ocw-store/src/lib.rs:967-1030`：`ReservationFilter` / `search_reservations` 已能按房号、姓名、状态、日期查询，可直接复用。

**改动点**
1. 后端新增 `export_reservations_csv(filter: ReservationFilter)`，按当前筛选条件查询，不把分页当作导出范围。
2. CSV 列建议：房号、客人姓名、入住日、退房日、晚数、状态、备注、操作员、创建时间、取消时间；状态输出中文（有效预定/已入住/已取消）。
3. 前端 `ReservationTab` 增加「导出 CSV」按钮，复用发卡导出的 ASCII 路径选择与 UTF-8 BOM 写法；文件名建议 `预定记录-YYYYMMDD-HHMMSS.csv`。
4. 导出按钮的权限、空结果提示和错误提示与发卡导出保持一致。

**验收标准**
- [ ] 预定记录页出现导出按钮，筛选条件变化后导出内容随之变化
- [ ] CSV 包含上述字段，日期/晚数/状态可读，Excel 打开中文不乱码
- [ ] 非授权角色无法调用导出命令
- [ ] 空结果导出只有表头，不报错

**待拍板**：导出是否仅管理员可见？建议与发卡导出一致=仅管理员；导出列是否包含操作员/创建/取消时间？建议包含，便于审计。
