# TD-504 代码签名

**优先级** P2 · **状态** 不排期（见总清单 §6）· **来源** RM6 · **模块** 工程与发布

**为什么做**：未签名的安装包在干净 Win11 上会触发 SmartScreen，现场装机要多点两次「仍要运行」。

**现状**【核实】：README §6 与 M6 均标注未做；v0.2 §14 明确「发布二进制但不做代码签名」。

**改动点**：拿到证书后在 `tauri.conf.json` 的 `bundle.windows` 配 `certificateThumbprint` 与 `timestampUrl`；无证书时保持现状。

**验收标准**
- [ ] 有证书的机器 `pnpm tauri build` 产物带有效签名
- [ ] 无证书的机器仍能正常打包（不能因此阻塞构建）

**依赖 / 风险**：需要外部证书，本机无法闭环 —— 因此排 P2。
**待拍板**：无
