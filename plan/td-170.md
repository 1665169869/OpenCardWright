# TD-170 移除水位/预警线与卡号强耦合字段

**优先级** P1 · **状态** 已完成 · **来源** US-1108-4 · **模块** 工程与发布

**为什么做**：水位线/预警线与数据库卡号字段对前台没有意义，且卡号已改为时间戳编码，
不再需要产品侧保存。

**改动点**
1. 删除 `card_no_status` / `set_water_warn_at` / `reset_water_mark` / `card_history` 命令与前端 API。
2. 不再读写 `setting.waterWarnAt` / `setting.startCardNo`；现有 `CardNo.state` 保留、不重置。
3. 发卡记录不再写 `issuance.card_no`，记录页/CSV 不再展示卡号；有效卡口径改为卡型 + 结果 + 到期。
4. 卡号仍在内部按时间戳生成并写入卡（客卡/总控卡）；总控卡接入 `--serial`。
5. 退房按记录 id（无卡退房）或卡号时间戳反查记录（持卡退房）；取消同号卡复用。

**验收标准**
- [x] 前端不再出现水位/预警线/卡号展示
- [x] 发卡记录新行 `card_no` 为 NULL，CSV 无卡号列
- [x] 持卡退房按时间戳匹配记录，无卡退房按记录 id
- [x] `cargo test --workspace` 126 项全绿，`tsc --noEmit` 通过
