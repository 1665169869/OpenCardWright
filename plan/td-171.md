# TD-171 恢复备份保留当前账号 + 返回恢复统计

**优先级** P1 · **状态** 已完成 · **来源** US-1108-5 · **模块** 记录与运维

**为什么做**：恢复备份会整库覆盖 `operator` 表，当前 admin 密码可能被备份里的旧密码替换；
同时恢复后没有明确的成功/失败记录数。

**改动点**
1. 恢复前 `snapshot_operators` 快照当前账号；恢复后按 `login` 合并：
   当前已有保留密码 / 角色 / 启用状态；备份新增导入停用；当前独有补回（部门置空）。
2. `RestoreResult` 返回房间 / 发卡 / 预定 / 账号数，以及保留 / 导入停用 / 补回 / 失败数。
3. 前端恢复提示展示这些计数；手册 / CHANGELOG / AGENTS 同步。

**验收标准**
- [x] 恢复后当前账号密码 / 角色 / 启用状态不被备份覆盖
- [x] 备份新增账号默认停用
- [x] 恢复提示包含业务记录数与账号处理数
- [x] `cargo test --workspace` 通过，`pnpm exec tsc --noEmit` 通过
