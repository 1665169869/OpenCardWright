# TD-158 钟点客卡与日租客卡的字节差异

**优先级** P2 · **状态** 已完成 · **来源** US-1106-49 · **模块** 发卡与卡片

**为什么做**：用户问「钟点房卡和客房卡字节是不是差不多」。按现有实现**推测只差 `页2[0]`**，
但没做过同条件逐字节对照——若真是如此，说明卡型是靠**时长码段**（`0x80`=天 / `0x40`=小时）区分的，
这对后续「按卡型判断」的逻辑（读卡识别、退房限制）很关键。

**现状**【推断，待实测】：

| 字段 | 日租客卡 | 钟点客卡 | 差异 |
|---|---|---|---|
| `页1[0..1]` | `5B EC` | `5B EC` | 相同 |
| `页1[2]` | `(序号 & 0x0F) << 4 \| 挂失` | 同左 | 相同 |
| `页1[3]` | `序号 >> 4` | 同左 | 相同 |
| **`页2[0]`** | **`0x80 \| 天数`** | **`0x40 \| (小时+1)`** | **不同** |
| `页2[1..2]` | 卡号（日/时/序号） | 同左 | 相同 |
| `页2[3]` | 年 + 月 | 同左 | 相同 |

**改动方向**
1. 同一房间、同一时刻，各写一张日租卡和钟点卡（`issue --days 1` / `issue --hours 3`）；
2. 逐字节对比 8 字节，确认差异是否**只有 `页2[0]`**；
3. 若还有别的差异（挂失位、卡号特殊值、页2[3]），补进技术规格。

**验收标准**
- [x] 两张卡的「差异字节清单」进 `抓包样本与验证记录.md`
- [x] 若只差 `页2[0]`，在技术规格 §4 明确写「卡型靠时长码段区分」
- [x] 若发现其它差异，更新 `CardBuilder` 并补 `selftest` 向量
