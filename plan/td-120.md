# TD-120 日历点击入住色块弹当前入住信息（纯展示）

**优先级** P2 · **状态** 已完成 · **来源** US-1106-20 · **模块** 房间与预订

**为什么做**：用户要求日历里点「已入住状态」（入住色块）能弹出当前入住的信息情况；此前色块 `pointerEvents: none` 不可点、数据也只有两个日期。

**现状**【核实】：`RoomCalendar.tsx` 入住色块（TD-116）背景色块无交互；`guestSpans` 只存 `{start, end}`，没有姓名/卡号/卡型。

**改动点**
1. `GuestSpan` 类型扩存 `guestName / cardNo / kind / days / hours / expiresAt`，拉取处同步写入。
2. 入住色块去 `pointerEvents: 'none'`，加 `onClick`（stopPropagation → `setStayDetail({roomNo, span})`）与 `cursor: pointer`，title 改「点击查看入住详情」。
3. 受控详情 Modal（`footer={null}` 纯展示）：`Descriptions` 展示房号、客人、卡型、卡号（0x 大写四位）、入住 → 到期、时长、状态（剩余 ≤24h 橙「即将到期」否则绿「有效」）、说明行（按发卡时间估算）。
4. 层叠：入住色块 `zIndex 0`、预定色块 `zIndex 1` 在上层——重叠区域点预定（改期/取消），非重叠区域点入住，互不干扰。

**验收标准**
- [x] 点入住色块弹详情，字段齐全
- [x] 无操作按钮（纯展示），X 关闭
- [x] 与预定色块点击互不干扰（zIndex 分层 + 各自 stopPropagation）
- [x] `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：数据沿用 TD-116 的 `list_issuances` 拉取（已扩字段，零新增查询）；到期按发卡时间估算，说明行已注明。
