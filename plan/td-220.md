# TD-220 入住登记单与独立登记表单

**优先级** P1 · **状态** 已完成 · **来源** US-1111-1 · **模块** 房间与预订

**为什么做**：以前的身份信息只能在发卡时填（`IssueForm` 的「客人身份」区），一张卡只能记一个人；
同一房间多位客人、只登记不发卡、换人续住都没有地方记。用户要求把身份登记从发卡流程里拆出来，
做成独立的「入住登记」：房间页和记录页各一个入口，读身份证可以连续登记多人。

## 现状（登记时）

- 身份信息挂在**发卡记录**上：`issuance` 表有 13 个字段（`guest_*` 8 个 + `id_*` 5 个）。
- 唯一写入点：`issue_guest` 收 `GuestInput`，写卡成功后调 `update_guest_identity`。
- 前端唯一入口：`IssueForm.tsx` 的「客人身份」区 + 「读取身份证」按钮。
- 「入住记录」页是 `list_issuances({ guestOnly: true })`，一行 = 一张卡 = 一个人。
- 结论：**一卡一人**，要支持多人登记必须改表结构。
