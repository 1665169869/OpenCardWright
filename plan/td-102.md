# TD-102 管理卡卡型默认「总控卡」

**优先级** P2 · **状态** 已完成 · **来源** ST-6 · **模块** 发卡与卡片

**为什么做**：总控卡是日常最常发的一类，默认停在「复位卡」上是个容易误发的默认值 —— 复位卡会清空该房间的卡记录。

**现状**【核实】：`app/src/pages/AdminCards.tsx:64` `const [kind, setKind] = useState<Kind>('reset')`。

**改动点**
1. 默认值改为总控卡对应的枚举值（`Kind` 的键名执行时核对，`type Kind` 在 `:31`）。
2. 核对切到总控卡后 `amount`（天数/小时）的默认值与总控档位是否匹配。

**验收标准**
- [x] 进入管理卡页，卡型下拉显示「总控卡」
- [x] 其余默认值不变（1 天 / 房间空 / 钟点 12:00）
- [x] `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：无（纯前端默认值）。
**待拍板**：无
