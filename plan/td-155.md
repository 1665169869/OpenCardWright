# TD-155 校时卡在真锁上是否真正生效

**优先级** P1 · **状态** 待办 · **来源** US-1106-47 · **模块** 发卡与卡片

**为什么做**：本轮已经把校时卡的字节与 demo **双向验证**（`页2[3]=0xAB`→demo 读 2611、`0xBB`→2711），
但**只证明「读卡器能读懂」，没证明「锁会用它校准 RTC」**。这两件事不等价。

**现状**【核实】：`tem_writetimercard_sdk` 反编译可见它会读卡校验 `页1[2] & 0x09 == 0x09`，
但**锁侧的时钟更新逻辑在锁固件里，无法静态确认**。

**改动方向**
1. 用 `PMSLockCard.exe issue --type timesync` 发一张（时间 = 写卡时刻）；
2. 找一把**时间明显偏差**的锁，刷这张卡；
3. 再用同一把锁发一张 1 小时钟点卡，看是否按新基准到期。

**验收标准**
- [ ] 刷校时卡后锁内时间被校准（用钟点卡到期时间间接验证）
- [ ] 若无效，排查是 `页2[0]`、时间戳还是锁固件版本问题
