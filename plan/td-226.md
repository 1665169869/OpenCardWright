# TD-226 BUG：退房（到期）提醒不播报

**优先级** P1 · **状态** 已完成 · **来源** US-1111-3 · **模块** 记录与运维

**为什么做**：前台反馈卡到点没有语音播报（可能连提示音也没有），只有弹窗或什么都没有。用户要求恢复播报。

## 现状【核实】链路

1. `app/src/App.tsx:180-204` 每 `REMINDER_POLL_MS` 调 `api.expiringCards(reminder.minutes)`；
2. 对每条新记录：`notification.warning(...)` + 语音
   `if (reminder.voice) spoke = speak(expirySpeech(...)); if (!spoke && reminder.sound) playAlert()`；
3. `speak()`（`app/src/utils/sound.ts:65-84`）：
   - 没有 `speechSynthesis` / `SpeechSynthesisUtterance` → `false`；
   - `voices.length > 0` 且没有 zh 音色 → `false`；
   - **`voices.length === 0`（音色列表尚未异步加载）时不会返回 false**，而是直接入队并返回 `true`；
4. `playAlert()`（Web Audio）依赖登录时 `unlockSound()` 在用户手势里解锁；未解锁时静默返回。

## 可疑点（按优先级复现）

1. **音色未加载**：WebView2 首次启动时 `getVoices()` 可能返回空数组，`speak()` 返回 `true` 但实际无声，
   而 `playAlert()` 因 `spoke === true` 不触发 —— 表现就是**完全没声音**。
2. **系统没有中文语音包**：`voices.length > 0` 但没有 zh → `speak()` 返回 false → 回退 `playAlert()`；
   若 Web Audio 未解锁（`unlockSound()` 只在登录按钮点击时调），回退也无声。
3. **设置开关**：`reminderEnabled` / `reminderVoice` / `reminderSound` 任一关闭；设置页「试听」与轮询路径不同。
4. **提醒窗口**：`expiring_cards` 只返回 `expires_at` 落在 `[now-10min, now+N min]` 的记录；
   轮询间隔大于窗口、或卡直接跳过窗口，就永远不会播报。
5. **去重集合**：`alerted` 按 `issuanceId` 去重，同一张卡只播一次；刷新页面后集合清空会重播。

## 改动点（先复现，再按根因修；以下是方向）

1. `speak()` 在 `voices.length === 0` 时**不要直接返回 true**：等待 `voiceschanged` 一次（短超时），
   或返回 false 让 `playAlert()` 兜底。
2. `playAlert()` 无法发声（`ctx === null` 或长时间 suspended）时给出可见提示，
   例如通知里追加「系统声音/语音包异常」。
3. 轮询间隔与提醒窗口对齐（`REMINDER_POLL_MS` vs `reminder.minutes`），必要时补一次「已过期」播报。
4. 设置页「试听」改为与真实提醒同一条路径（`speak` 优先、失败回退 `playAlert`），避免「试听能响、到点不响」。
5. 系统通知方案见 **TD-228**（系统 toast + 应用内通知双管），两条分开验收。

## 完成记录

2026-11-12 · 26.11.1015 · 本轮提交

**根因（代码确认）**：`speak()` 在 `voices.length === 0`（音色列表异步未加载）时**没有返回 false**，
而是直接入队并返回 `true`；调用方看到 `true` 就不触发 `playAlert()` 回退 —— 表现就是**完全没声音**。

- `sound.ts`：`voices.length === 0` 与「没有 zh 音色」一律返回 `false`；新增 `primeSpeech()`
  并在 `unlockSound()` 里预热音色（它已在首次 `pointerdown` 调用）。
- `tryPreview(voice)`：与真实提醒同一条路径（语音优先 → 提示音兜底），返回 `{ spoke, sounded }`；
  设置页按三种结果给文案（已语音 / 无中文语音包已用提示音 / 完全不支持）。
- `App.tsx`：语音降级时只记一条 `logFrontend` warn（`voiceWarned` ref），便于现场排查。
- 轮询间隔与窗口本次未改：`REMINDER_POLL_MS = 30s`，`expiring_cards` 窗口 `[now-10min, now+N]`，
  30s 轮询不会漏窗，暂不需要调整。
- **现场验证待办**：用户需在有中文语音包 / 无中文语音包两种机器上各试一次「试听」与真实到点提醒。
