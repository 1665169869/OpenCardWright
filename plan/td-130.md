# TD-130 仓库改名为 OpenCardWright + 产品目录改 app（消除中文路径）

**优先级** P2 · **状态** 已完成 · **来源** US-1106-32 · **模块** 工程与发布

**为什么做**：仓库目录名是中文「门锁」，导致两处长期绕路——MSVC 在中文路径下报 `D8050`（必须设
`CARGO_TARGET_DIR='C:\ocw-target'`，安装包也就跑到仓库外）、NSIS 安装器在中文路径/中文文件名下可能报
`Error writing temporary file`。用户提议把根目录改成英文项目名，产品子目录改个短名。

**现状**【核实】：引用集中在 `.gitignore`（6 条规则）、`AGENTS.md`（17 处）、`app/README.md`、`plan/待办清单.md`
（19 处）、建设方案（2 处）；`tauri.conf.json` 的 `frontendDist`、Cargo workspace、`scripts/*.ps1` 全是相对路径。

**改动点（已执行）**
1. 引用与配置：`.gitignore` 规则、四个文档的 `opencardwright/` → `app/` 全部替换（grep 残留 0）；README §4
   中文路径坑降级为「历史注记」，说明默认 target 回到 `app/src-tauri/target/`；打包节产物位置改 `app/output/`。
2. 内部标识不动：`package.json` / Cargo crate name 仍是 `opencardwright`；`identifier` 不变。
3. 目录改名（本条目完成记录的收尾动作）：`D:\source-code\门锁` → `D:\source-code\OpenCardWright`；
   `OpenCardWright\opencardwright` → `OpenCardWright\app`。

**验收标准**
- [x] 四个文档 + `.gitignore` 的 `opencardwright/` 路径引用全部改为 `app/`（grep 残留 0）
- [x] README 说明：仓库 ASCII 路径后 `CARGO_TARGET_DIR` 不再必需；产物位置 `app/output/`
- [x] `pnpm exec tsc --noEmit` + `cargo test --workspace` 在旧路径下全绿后才动目录
- [x] 改名完成后在新路径重跑构建（`app/` 下 `pnpm install` + `tsc`）

**依赖 / 风险**：改名后**当前会话的 workspace 路径失效**（需重开对话）；`node_modules` 里含旧绝对路径，
换路径后必须重新 `pnpm install`；「门锁」目录名在部分文档正文里作为产品中文名出现（如「门锁发卡台」），
**只替换路径形态**（`opencardwright/`、`门锁` 作为目录），不动产品名。
