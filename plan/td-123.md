# TD-123 日历每月展示上月末日（前导）+ 下月 1 号（尾部至少 1 天）

**优先级** P2 · **状态** 已完成 · **来源** US-1106-23 · **模块** 房间与预订

**为什么做**：月视图边界不完整 —— 看不到上个月最后一天；无跨月数据时右侧连下月 1 号都不显示（TD-117 的溢出按数据动态 0–7 天），翻月交界处不直观。

**现状**【核实】：`RoomCalendar.tsx` 的 `days` = 当月 + 动态溢出（`overflowDays` 按预定 `checkOut` / 客卡到期日算，0–7 天封顶，无跨月即 0）；无前导列；`spanOf` / `guestSpanOf` / `overflowDays` 均按 `dayjs.diff(month, 'day')` 绝对列坐标计算，头部插列会整体偏移。

**改动点**
1. `days` 头部固定加**上月最后一天** 1 列（前导列；过去日期按 TD-112 锁定不可点）。
2. 尾部溢出改 `max(1, overflowDays)` —— 至少含下月 1 号，跨月动态溢出继续取最大。
3. **坐标系统一**：前导列使「列 index = diff(month) + 1」，`spanOf` / `guestSpanOf` / `overflowDays` / 色块 `left/width` 与视窗截断全部换算（主要风险点，需跨月色块回归）。
4. 前导/尾列样式沿用 TD-117：浅灰 `#f5f5f5` + `M/D` 标注，今天/周末高亮按绝对日期。

**验收标准**
- [ ] 每月视图左侧固定显示上月最后一天，右侧至少显示下月 1 号
- [ ] 跨边界色块位置正确（10-31 → 11-01、11-30 → 12-01 半格错位不乱）
- [ ] 前导列（过去日期）不可点预定；尾列未来日期可点
- [ ] 无跨月数据时尾部仍有下月 1 号；有跨月数据时溢出仍最多 7 天
- [ ] `cargo test --workspace` + `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：与 TD-117 动态溢出共存（尾部取 max）；**列坐标偏移是易错点**——所有 `diff(month)` 换算与色块截断要一并改，回归覆盖两条跨边界场景。
