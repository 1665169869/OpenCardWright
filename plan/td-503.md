# TD-503 `list_room_types.room_count` 排除已删房

**优先级** P1 · **状态** 已完成 · **来源** CL-0036-2 · **模块** 工程与发布

**为什么做**：设置页房型的「N 间」与「删除房型」的占用检查会把逻辑删除的房间算进去，数字与房间页对不上。

**现状**【核实】：`crates/ocw-store/src/lib.rs:1076`
`(SELECT COUNT(*) FROM room r WHERE r.room_type_id = t.id)`，**没有 `r.active = 1`**；
同文件 `delete_room_type` 的占用检查要同步改。

**改动点**
1. 两处 SQL 都加 `AND r.active = 1`。
2. 补单测：删房前 count=1 → 逻辑删除后 count=0。

**验收标准**
- [x] 逻辑删除一间房后，房型「N 间」减 1
- [x] 该房型下房间全删光后，允许删除该房型（删除前先摘掉已删房的外键引用）
- [x] 单测覆盖上述两条（`room_type_count_excludes_deleted_room` / `deleted_room_frees_room_type`）

**依赖 / 风险**：只改查询口径，不动 `list_rooms`（它按设计返回全量，见 AGENTS §9 业务铁律）。
**待拍板**：无
