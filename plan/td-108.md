# TD-108 日历加大 + 色块跨天带姓名备注 + 预定按钮回右键 + header 固定

**优先级** P2 · **状态** 已完成 · **来源** US-1106-8 · **模块** 房间与预订

**为什么做**：用户试用后四点反馈：日历太小看不清预定信息；房间卡片上的「预定」按钮要放回右键菜单；主窗口顶栏滚动时应固定；色块要把退房日也画出来并显示姓名与备注。

**现状**【核实】：原 `RoomCalendar` 列宽 44 / 行高 36 / 可视区 64vh；色块文字只有「姓名 + 日期」；卡片 header 有「预定」按钮；`App.tsx` 的 `Header` 无 sticky。

**改动点**
1. `RoomCalendar.tsx`：`COL_W 44→64`、`ROW_H 36→44`、房号列 `84→100`、可视区 `64vh→78vh`。
2. 色块区间改**含退房日**（`checkOut + 1 天` 截断到次月 1 日）：今天→明天的入住在今天、明天两列都显示。
3. 色块文字 = `姓名 · 备注`（都填了才拼接），没有才退回日期区间；tooltip 带完整日期、姓名、备注。
4. `RoomManager.tsx`：删卡片「预定」按钮，`roomMenu` 加回「预定房间」项；日历空白格直接预定的入口保留。
5. `App.tsx`：`Header` 加 `position: sticky / top: 0 / zIndex: 10`。

**验收标准**
- [x] 列宽行高加大、可视区 78vh，色块显示姓名与备注
- [x] 退房日当天的列有色块（含退房日）
- [x] 房间卡片无「预定」按钮，右键菜单有「预定房间」
- [x] 顶栏滚动时固定（水位/到期提醒始终可见）
- [x] `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：纯前端展示层，不改数据模型；退房日含入显示导致相邻预定（6→7 与 7→8）在 7 号列叠放，半格错位方案另立 TD-110。
**待拍板**：无（四项均为用户明确要求）
