# TD-207 房态日历顶部增加「新增预定」按钮

**优先级** P2 · **状态** 已完成 · **来源** US-1109-3 · **模块** 房间与预订

**为什么做**：目前日历只能点空白格预定；如果客人先打电话、还没确定房号，或操作员想从顶部统一入口新建，缺少一个全局按钮。

**现状**
- `app/src/components/RoomCalendar.tsx:300-325`：日历顶部只有月份切换、回到今天、房型筛选和说明文字，没有新增预定入口。
- `app/src/pages/RoomManager.tsx:641-662`：`openReserve(room, date)` 需要 `Room` 对象；空白格点击时已有房间上下文。
- `app/src/components/ReservationModal.tsx:24-41`：弹窗需要 `room`（或 `editing`），没有“未指定房间”模式。

**改动点**
1. 在日历顶部操作区增加「新增预定」按钮，位置与月份/房型筛选同排，窄窗口自动换行。
2. 点击后先选择房间（复用房间列表的 Select/搜索），再打开 `ReservationModal`；默认入住日取今天，退房日按晚数联动。
3. 已选中房间时直接复用现有 `openReserve(room, date)`，不复制弹窗逻辑。
4. 预定成功后刷新日历，并保持当前月份/房型筛选。

**验收标准**
- [ ] 日历顶部有「新增预定」按钮，管理员/前台按现有权限可见
- [ ] 未指定房间时能选择房间；选定后打开现有预定弹窗
- [ ] 保存成功后日历立即出现色块，月份/筛选不被重置
- [ ] 窄窗口按钮不溢出、不遮挡月份导航

**待拍板**：未指定房间时的选择方式？建议顶部按钮先弹房间 Select（可搜房号），而不是默认第一间房。
