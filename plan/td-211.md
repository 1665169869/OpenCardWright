# TD-211 预定间夜列与凌晨房归属（12:00 边界）

**优先级** P1 · **状态** 已完成 · **来源** US-1109-4 · **模块** 房间与预订

**为什么做**：房态日历现在按自然日画预定，无法表达「凌晨 0–12 点入住、当天 12 点退房」的间夜归属。
用户要求每列代表一个间夜（当天 12:00 ～ 次日 12:00），凌晨房归到前一晚的列。

## 现状（代码已改，尚未收口）

工作区已有未提交改动，核心链路已接上，但尚未做最终手工验收与文档同步：

- 数据库：`reservation` 新增 `check_in_time` / `check_out_time`（默认 `12:00`），迁移 `apply_v11`；当前 `SCHEMA_VERSION=12`（v12 仅追加 raw_hex 索引）。
- 存储：`Reservation` / `ReservationInput` / `Reservation` 查询增加时间；校验改为完整区间：
  - 退房时间必须晚于入住时间；
  - 允许同一天入住/退房（如 `D 02:00 → D 12:00`）；
  - 时间格式 `HH:mm`；
  - 重叠、`reservation_covers_today`、房态同步改用完整区间。
- 日历：`RoomCalendar` 的 `spanOf` / `bookedToday` 使用 `nightStart` / `nightOverlap`，
  列 = `[D 12:00, D+1 12:00)`；凌晨房会落在 `D-1` 列。
- 查询：`list_reservations` 查询范围前后各放宽一天，日历调用从 `leadDay` 起取。
- 表单：`ReservationModal` 增加入住/退房 `TimePicker`，默认 12:00；同日凌晨房可提交。
- 展示：记录页显示入住/退房时间；日历色块提示显示完整日期时间。
- 新增测试：`reservation_time_interval_edges`（默认 12:00、同日凌晨房、零时长、12:00 边界、多晚区间、重叠）。
