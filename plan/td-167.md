# TD-167 记录页新增「预定记录」查询

**优先级** P1 · **状态** 已完成 · **来源** US-1108-1 · **模块** 记录与运维

**为什么做**：日历只能看当前视窗内**有效**的预定（`list_reservations` 固定 `status='booked'`），
已取消、已入住的预定在界面里消失，前台无法核对历史、追溯取消原因。记录页需要一个可筛选的分页查询。

**现状**【核实】：`Logs.tsx:49` 只有「发卡记录 / 入住记录 / 操作审计」三个 tab；
`ocw_store::list_reservations`（`lib.rs:962`）只返回 `status='booked'`，且不分页；
`Reservation`（`lib.rs:777`）已含 `status / created_at / cancelled_at / operator_name`。

**改动点**
1. `ocw-store`：新增 `ReservationFilter` + `search_reservations()`，支持房号前缀、客人姓名模糊、
   `status`（booked / checked_in / cancelled）、入住日区间与分页，按入住日倒序。
2. `commands.rs`：新增 `list_reservation_records`（Level::Login），同步命令矩阵。
3. `api.ts`：新增 `ReservationFilter` 与 `listReservationRecords()`。
4. `Logs.tsx`：新增「预定记录」tab，筛选栏 + 分页表格；只读，不改期/取消。
5. `app/README.md` §8 命令 × 角色表登记新命令。

**验收标准**
- [x] 记录页出现「预定记录」tab，前台可访问
- [x] 可按房号 / 姓名 / 状态 / 入住日区间筛选，分页正确
- [x] 已取消（cancelled）与已入住（checked_in）的记录都能查到
- [x] `cargo test -p ocw-store` 覆盖筛选与分页；`cargo test --workspace` 全绿
- [x] `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：只读查询，不动 `sdk/`；新增命令必须同步 `README.md` §8 与矩阵，否则
`auth_matrix_matches_every_command` 会红。
