# TD-168 CSV 导出目录改用系统 Known Folder

**优先级** P1 · **状态** 已完成 · **来源** US-1108-2 · **模块** 记录与运维

**为什么做**：本机把桌面重定向到 D 盘或其他盘后，导出的 CSV 仍落到 C 盘旧桌面，
前台以为文件没生成或找不到导出结果。

**现状**【核实】：`export_dir()`（`commands.rs:3282`）用 `%USERPROFILE%\Desktop` 硬拼；
Windows 重定向桌面后旧 `C:\Users\<用户>\Desktop` 可能仍存在，`is_dir()` 判真即返回。

**改动点**
1. `Cargo.toml` 增加 `dirs = "7"`（lock 已有 7.0.0，不新增下载）。
2. `export_dir()` 改用 `dirs::desktop_dir()` → `dirs::download_dir()` → `data_root()/exports`；
   删除 `USERPROFILE` / `OneDrive` 手工拼接。
3. 抽出 `pick_export_dir()` 并加单元测试。

**验收标准**
- [x] 桌面重定向到 D 盘时，导出路径与系统 Known Folder 桌面一致
- [x] 桌面不可用时回退到系统下载目录，再回退到数据目录 `exports`
- [x] `cargo test --workspace` 127 项全绿，`cargo check` 零警告

**依赖 / 风险**：只影响导出落点，不改 CSV 内容；`dirs` 是已有间接依赖。

**待拍板**：无
