# TD-109 关窗确认框：缩小到系统托盘（默认）或退出

**优先级** P2 · **状态** 已完成 · **来源** US-1106-9 · **模块** 工程与发布

**为什么做**：点 X 直接退出会丢掉正在操作的上下文；用户要求关闭时弹确认框，选「缩小到状态栏（已拍板 = 系统托盘）」还是「关闭程序」，默认缩小。

**现状**【核实】：`tauri.conf.json` 无托盘配置；`main.rs` 未拦 `CloseRequested`，点 X 即退；无任何托盘图标。

**改动点（拍板：「状态栏」= 系统托盘，不是任务栏最小化）**
1. `Cargo.toml`：tauri 开 `tray-icon` feature。
2. `main.rs`：`CloseRequested` → `prevent_close()` + emit `close-confirm`；建托盘（左键恢复窗口，右键菜单「显示主窗口 / 退出程序」）；single-instance 二次启动先 `show + unminimize + set_focus`（窗口可能藏在托盘）。
3. `commands.rs`：`hide_to_tray` / `quit_app`（均 Login 级，登记 MATRIX，计数 35/28/6 = 69）。
4. `App.tsx`：`listen('close-confirm')` 弹三按钮确认框——**缩小到托盘（推荐，默认）** / 退出程序 / 取消；取消即继续使用。
5. `api.ts` 加 `hideToTray` / `quitApp` 封装。

**验收标准**
- [x] 点 X / Alt+F4 弹确认框，不直接退出
- [x] 默认按钮是「缩小到托盘」；缩小后进程继续（到期提醒、自动备份不中断），托盘左键或菜单可恢复
- [x] 「退出程序」真正退出；托盘菜单「退出程序」同样可退
- [x] 二次启动程序能把托盘里的窗口叫回前台
- [x] `cargo test --workspace` 118 项全绿（含鉴权矩阵 69 条）；`pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：tray-icon 是 tauri 官方 feature；`app.exit(0)` 跳过全部清理（SQLite WAL 由 SQLite 自身恢复，风险可接受）。界面视觉验收待用户过一遍。
