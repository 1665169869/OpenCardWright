# TD-506 硬件层迁到 rc-device-sdk

**优先级** P1 · **状态** 已完成 · **来源** 用户需求（2026-11-14） · **模块** 发卡与卡片 / 工程与发布

**为什么做**：原 `sdk/`（.NET SDK + CLI + COM）虽然能用，但把「卡字节」「房号→序号映射」
「流程编排」混在一份 csc 现编的产物里，耦合度过高：产品侧要自己拼 CLI 参数、解析 GBK 文本
输出、实现模拟构包，身份证读取还散落在前端 WebSocket。要求是：删除原 SDK，硬件兼容全部交给
独立仓库 **rc-device-sdk**；前端只负责展示层。

**现状**【核实】：`sdk/` 已删除；硬件层以 git submodule 挂在 `app/src-tauri/vendor/rc-device`；
门锁卡经 32 位 `rc-device-sidecar.exe`（NDJSON）操作；身份证经 `read_id_card` 走硬件层的
9001 客户端；前端不再含任何硬件协议代码。

**改动点**

1. 上游（rc-device-sdk，提交 `93c2f65` / 它的 TD-020）：
   `RawSpec` + `build_raw` + `CardDevice::write_raw`、`Operation::WriteRaw`、
   内存模拟后端 `SimCardDevice`、sidecar `--sim` / `--sim-card`、`probe --sim`，
   以及 README / AGENTS / `docs/card-format.md` 同步。
2. 本仓库：
   - submodule + `rc-device` path 依赖（`[workspace] exclude`，不进产品 workspace）；
   - 手动构建（无脚本）：`cargo build --target i686-pc-windows-msvc` + 拷 exe/驱动到 `resources/device`
     + 46 项自检门禁；驱动指纹改由 `provision.rs` 启动时现算 SHA-256（不再生成 `manifest.json`）；
   - `ocw-device` 重写为「常驻 sidecar 会话 + DTO 映射 + 错误翻译 + 进程内模拟」；
   - `commands.rs` 全量 typed spec（删 `to_args` 与全部 `--type/--room/--days` 字符串）；
   - `cardno.rs` 用 `rc_device` 编码/进位，保留 `CardNo.state` 与回拨保护；
   - 新增 `read_id_card` 命令，前端删 `src/idcard.ts`；
   - 资源目录 `resources/sdk` → `resources/device`。
3. 文档：AGENTS.md / 根 README / app/README / NOTICE / 使用手册 / CHANGELOG 同步。
