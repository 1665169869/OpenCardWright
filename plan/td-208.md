# TD-208 新增预定支持选择晚数

**优先级** P2 · **状态** 已完成 · **来源** US-1109-3 · **模块** 房间与预订

**为什么做**：现在只能分别选入住日和退房日，前台要自己算晚数；希望直接选「住几晚」，由表单自动推出退房日，减少算错日期。

**现状**
- `app/src/components/ReservationModal.tsx:44-50`：`checkIn` / `checkOut` 两个日期状态。
- `app/src/components/ReservationModal.tsx:105`：提交条件只校验 `checkOut > checkIn`。
- `app/src/components/ReservationModal.tsx:148-154`：晚数只作为只读摘要展示，不能编辑。

**改动点**
1. 增加「晚数」输入（InputNumber 或 Select），范围至少 1 晚；默认按当前入住/退房差计算。
2. 修改晚数时自动把退房日设为 `入住日 + 晚数`（退房日仍不含当日）。
3. 修改入住日时保持晚数不变、重算退房日；修改退房日时反算晚数。
4. 编辑已有预定时，初始晚数按原入住/退房计算；后端重叠/日期校验仍为最终兜底。

**验收标准**
- [ ] 新建预定可选晚数，退房日随晚数变化
- [ ] 入住日变化后晚数保持，退房日同步
- [ ] 退房日不早于入住日 + 1 天，非法值不能提交
- [ ] 编辑预定打开时晚数与原日期一致

**待拍板**：晚数上限是否跟随后端允许的最大日期范围？建议不设窄上限，仅校验退房日合法与不重叠。
