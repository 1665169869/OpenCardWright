# TD-143 实测「退房回收卡」的真实字节

**优先级** P1 · **状态** 待办 · **来源** US-1106-42 · **模块** 发卡与卡片

**为什么做**：原厂文档明确「退房回收卡片」的参数是 `fksj=00000000, xh=0, sjdw=0, sjlength=1, gs=0`——
注意 **`sjlength=1` 不是 0**。我们的空白卡/持卡退房擦卡写的是全零 8 字节，**可能与原厂回收卡不等价**。
如果不等价，现场会出现「以为擦干净了，但锁仍认这张卡」的风险。

**现状**【核实】：`sdk/CardBuilder` 的 raw 通道写 `00000000/00000000`；原厂参数组合见
`docs/原厂SDK-v4.2-分析.md` §3「关键规则 4」。

**改动方向**
1. 用原厂 `RWCardDemo.exe` 按官方参数写一张回收卡，读回 8 字节；
2. 与我们的空白卡（`PMSLockCard.exe issue --type raw --p1 00000000 --p2 00000000`）逐字节对比；
3. 差异登记进 `docs/抓包样本与验证记录.md`；
4. 若确实不同，评估是否改用原厂参数组合（涉及 `sdk/`，需拍板）。

**验收标准**
- [ ] 回收卡样本入抓包表，标注来源与参数
- [ ] 明确结论：我们的空白卡与原厂回收卡是否等价
- [ ] 若不等价，给出「锁对两者的反应」实测记录

**依赖 / 风险**：需要原厂授权卡 + 专用读卡器 + 真锁；未授权时原厂写卡返回 128。
**待拍板**：无（先实测取证，改不改另行决定）
