# TD-222 入住登记入口扩展（房间页工具栏 + 记录页新增）

**优先级** P1 · **状态** 已完成 · **来源** US-1111-2 · **模块** 房间与预订

**为什么做**：TD-220 只把「入住登记」放在房间卡片右键菜单和记录页 tab 里。用户要求：
房间页「新增房间」旁边再放一个「入住登记」按钮；记录页的「入住登记」页顶部也要有新建入口，
让前台不用先找到某个房间的右键菜单。

## 现状【核实】

- 房间页工具栏（`app/src/pages/RoomManager.tsx:905-913`）只有「新增房间」（管理员可见）与「读卡退房」，
  没有入住登记入口；右键菜单里已有 `{ key: 'checkin', label: '入住登记' }`。
- `CheckinForm`（`app/src/components/CheckinForm.tsx`）支持不传 `roomNo`：弹窗内显示房号输入框 + 「开始登记」。
- 记录页「入住登记」tab（`app/src/pages/Logs.tsx:55`）只渲染 `CheckinTab` 列表，没有「新增登记」按钮。

## 改动点

1. 房间页工具栏：在「新增房间」后加 `<Button icon={<UserAddOutlined />}>入住登记</Button>`，
   点击 `setCheckinRoom('')`（空字符串表示不预填房号），由已有的 `<CheckinForm open roomNo={...}>` 打开；
   `CheckinForm` 在房号为空时已经会显示输入框，不需要改组件。
2. 记录页 `CheckinTab`：筛选区加「新增登记」按钮（登录即可，不做管理员限制），点击打开同一个 `CheckinForm`
   （不预填房号），`onSaved` 里调 `load()` 刷新列表。
3. 权限：两个入口都只调已有登录级命令，**不需要新增命令、不改权限矩阵**。

## 验收标准

- [ ] 房间页工具栏出现「入住登记」，点开可在弹窗里输入房号建单
- [ ] 记录页「入住登记」页出现「新增登记」，建单成功后列表自动刷新
- [ ] 两个入口与右键菜单进入的是同一套表单，同房复用同一张 open 单
- [ ] 前台（frontdesk）也能用，不报权限错误
- [ ] `pnpm exec tsc --noEmit`、`pnpm exec vite build` 通过
