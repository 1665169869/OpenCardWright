# TD-166 清除前端「卡号」字段残留

**优先级** P2 · **状态** 已完成 · **来源** US-1106-51 · **模块** 记录与运维

**为什么做**：用户要求「全面搜索卡号字段残留，让前端不再展示卡号」——十六进制卡号对前台没意义，
而且「卡型 + 房号 + 发卡时间」足以识别一张卡。

**现状**（`grep 卡号 src/`）：
- `Logs.tsx:273`、`428`：两个列表的「卡号」列
- `Logs.tsx:512`：详情弹窗的「卡号」行
- `Logs.tsx:158`：搜索框 placeholder「卡号（十进制）」
- `Logs.tsx:133`、`241`：注释与「该卡没有卡号」提示 —— **保留**
- `AdminCards.tsx:50/54`、`RoomManager.tsx:1441/1445`：卡片说明文字 —— **保留**（解释卡里有什么，不是数据展示）
- `ReadCard.tsx:75`：「该卡号共 N 条」→ 改「该卡共 N 条记录」

**改动方向**
1. 删 `Logs.tsx` 两个列表的卡号列 + 详情弹窗的卡号行
2. 搜索框 placeholder 改成不涉卡号的措辞
3. `ReadCard.tsx:75` 文案改
4. **保留**说明性文字

**验收标准**
- [x] 界面上不再出现 `0xXXXX` 形式的卡号展示
- [x] 按卡号搜索的能力仍可用（只是不给提示文案）
- [x] `tsc --noEmit` 通过

**待拍板**：搜索框是否保留「按卡号搜索」——建议**保留**（排障要用）
