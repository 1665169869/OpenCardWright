# TD-118 入住记录 tab（填了身份信息的发卡视图）

**优先级** P1 · **状态** 已完成 · **来源** US-1106-18 · **模块** 记录与运维

**为什么做**：用户要「入住记录」——记录每次发卡的入住情况，且**未输入身份信息不记录入住信息**。发卡记录里混着没填身份的卡，缺少一个「谁、哪间房、住到什么时候」的入住视角。

**现状**【核实】：`issuance` 表已存每次发卡与客人身份（`guest_name` 等，v3 迁移），但没有按身份过滤的视图；`IssuanceFilter` 无相关条件；`Logs.tsx` 只有「发卡记录 / 操作审计」两个 tab。

**改动点（已拍板：复用发卡记录做视图，不建新表）**
1. `ocw-store`：`IssuanceFilter` 加 `guest_only: bool`；`list_issuances` 追加 `guest_name IS NOT NULL AND TRIM(guest_name) != ''`（NULL / 空白都不算），单测 `guest_only_excludes_blank_names`。
2. `commands.rs`：`list_issuances` 加 `guest_only: Option<bool>` 透传；CSV 导出构造固定 `false`（导出不受视图过滤）。
3. `api.ts`：`LogFilter` 加 `guestOnly`，`listIssuances` 传参。
4. `Logs.tsx`：新增 `CheckinTab` 并注册为第三 tab「入住记录」——固定 `guestOnly: true`，筛选房号 + 入住起止日，列 = 入住时间 / 房号 / 客人 / 卡型 / 时长 / 卡号 / 到期 / 状态（派生同发卡记录），分页 + 60 秒到期重渲染，提示「未填写的不计入入住记录」。

**验收标准**
- [x] 填了姓名的发卡出现在入住记录；NULL / 空白姓名的不出现（`guest_only_excludes_blank_names`）
- [x] 房号 / 入住起止日筛选与分页正常
- [x] 状态派生与发卡记录一致（失败 / 已退房 / 已过期 / 有效）
- [x] `cargo test --workspace` 119 项全绿；`pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：零 schema 改动（视图方案）；证件号不加列（与发卡记录口径一致，导出走发卡记录 CSV）。
