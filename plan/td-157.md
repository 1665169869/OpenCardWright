# TD-157 总控卡专用挂失卡

**优先级** P3 · **状态** 待办 · **来源** US-1106-48 · **模块** 发卡与卡片

**为什么做**：用户指出「总控卡的挂失有**专门的总控卡挂失卡**」——这与我们现有的
「客卡挂失 = `页1[2]` 低 4 位 = 1」很可能**不是同一套机制**。我们不实现它，总控卡丢失后就无法作废。

**现状**【核实】：`CardBuilder` 目前只有 `BuildGuestDay/Hour(..., lost)`、`BuildMaster(...)`；
`AdminCardRequest` 里**没有「总控卡挂失」卡型**；`RWCardDemo` 的卡型下拉也未见对应项。

**改动方向**
1. 用原厂主软件（旧电脑那套）发一张总控卡挂失卡，记录 8 字节；
2. 与客卡挂失（`页1[2]` 低 4 位）对比：是否复用同一位、还是另有标志字节；
3. 若确认存在，在 `AdminCardRequest` 增加卡型 + 产品侧「管理卡」页入口；
4. 文档补「总控卡挂失」与「客卡挂失」的区别说明。

**验收标准**
- [ ] 总控卡挂失卡的字节有实测记录
- [ ] 与客卡挂失的字段差异写清
- [ ] 若新增卡型：`selftest` 有向量、产品侧有入口、鉴权矩阵登记
