# TD-405 文件日志 + 轮转

**优先级** P2 · **状态** 已完成 · **来源** P15 · **模块** 记录与运维

**为什么做**：现场排障没有日志文件可拿，只能让用户复制终端输出。

**现状**【待复核】：`Cargo.toml` 依赖里没有 `tauri-plugin-log`；日志目前只走 `log_frontend` 与 stdout。

**改动点**
1. 不引入新插件，用 `std::fs` 写 `%PROGRAMDATA%\OpenCardWright\logs\ocw-YYYYMMDD.log`。
2. 启动时做一次轮转：单文件 > 5 MB 改名，保留 5 份。
3. `log_frontend` 与 Rust 侧关键 `eprintln!` 同时落文件。

**验收标准**
- [x] 日志按天生成，超过 5 MB 自动切分
- [x] 只保留最近 5 份（且不误删非日志文件）
- [x] 不新增 crate 依赖（`std::fs` 手写，时区偏移问一次 SQLite）
