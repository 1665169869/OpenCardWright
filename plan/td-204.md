# TD-204 房态日历增加独立房型筛选

**优先级** P1 · **状态** 已完成 · **来源** US-1108-1 · **模块** 房间与预订

**为什么做**：日历当前直接使用房间页的 `visible`，房型/房态筛选一动日历跟着变，想「只看某房型」
必须先退回房间视图改筛选。日历需要自己的房型筛选，且与房间页互不影响。

**现状**【核实】：`RoomManager.tsx:919` 传 `rooms={visible}`；`RoomCalendar.tsx:74` 注释写明
「跟随房间页的房型 / 房态筛选」，行渲染直接 `rooms.map`（`RoomCalendar.tsx:365`）。

**改动点**
1. `RoomManager.tsx`：日历改传全量 `liveRooms`，并传 `roomTypes`。
2. `RoomCalendar.tsx`：新增本地 `typeFilter`（全部 / 各房型 / 未分类），头部加房型选择；
   行渲染改用筛选后的 `rows`，空状态区分「没有房间」与「该房型下没有房间」。
3. 日历的房型筛选只影响行显示，不影响预定 / 入住数据的拉取与跨月色块计算。

**验收标准**
- [x] 日历头部可切换房型，切换后只显示该房型的房间
- [x] 房间页切换房型 / 房态，日历内容不再变化
- [x] 日历内切换房型不影响房间页筛选
- [x] `pnpm exec tsc --noEmit` 通过

**依赖 / 风险**：纯前端；不动 `sdk/` 与后端。

**待拍板**：无
