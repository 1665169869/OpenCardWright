# TD-165 入住记录允许导出 CSV

**优先级** P1 · **状态** 已完成 · **来源** US-1106-51 · **模块** 记录与运维

**为什么做**：发卡记录已有「导出 CSV」（`IssuanceTab`，仅管理员可见），但**入住记录 tab 没有**。
前台核对入住名单、交接班、税务/公安报送都要按「填了身份信息的记录」导出。

**现状**：`export_issuances_csv`（`commands.rs:3234`）不支持 `guest_only`；`CheckinTab`（`Logs.tsx:309`）
没有 `canAdmin` prop、没有导出按钮。

**改动方向**
1. 后端：`export_issuances_csv` 加 `guest_only: Option<bool>`，透传给 `IssuanceFilter`
2. `api.ts`：`exportIssuancesCsv(f, guestOnly?)`
3. `Logs.tsx`：`CheckinTab` 加 `canAdmin` prop；筛选栏旁复制「导出 CSV」，调 `exportIssuancesCsv(filter, true)`

**验收标准**
- [x] 入住记录 tab 有导出按钮，仅管理员可见
- [x] 导出内容 = 当前筛选条件下**填了身份信息**的记录
- [x] CSV 列与发卡记录一致（含证件 5 字段）
