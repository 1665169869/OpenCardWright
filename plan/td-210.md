# TD-210 入住/退房日期合并为一个功能区

**优先级** P2 · **状态** 已完成 · **来源** US-1109-3 · **模块** 房间与预订

**为什么做**：当前入住、退房是两个分散的 `span` + DatePicker，视觉上像两个独立字段；希望合并成一个订房日期功能区，把开始、结束、晚数放在同一块里，减少误操作。

**现状**
- `app/src/components/ReservationModal.tsx:120-146`：入住和退房各用一个 `span` 包裹 DatePicker，靠外层 `Space` 横向排列。
- `app/src/components/ReservationModal.tsx:148-154`：晚数摘要在日期控件下方单独一行。

**改动点**
1. 用一个带边框/背景的日期功能区承载入住日、退房日、晚数摘要（可继续用两个 DatePicker，也可用 RangePicker）。
2. 保持现有日期语义：退房日不含当日；改期/新建共用同一组件。
3. 窄窗口下日期区自动换行，晚数摘要与日期同区显示。
4. 不改变后端接口与表单字段名，避免影响保存/改期逻辑。

**验收标准**
- [ ] 入住/退房/晚数在视觉上属于同一个功能区
- [ ] 新建、改期、取消流程行为不变
- [ ] 1024 宽度下日期区不溢出、不遮挡按钮
- [ ] 退房日必须晚于入住日的校验仍生效

**待拍板**：用 RangePicker 还是保留两个 DatePicker 但同区展示？建议保留两个 DatePicker（现有 disabledDate/改期逻辑改动最小），只重排布局。
